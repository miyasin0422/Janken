# じゃんけんゲーム

Defoldを使用して個人制作した、シンプルなじゃんけんゲームです。

グー・チョキ・パーから手を選択してCPUと対戦し、
できるだけ多くの連勝記録を目指します。

通常のランダムなじゃんけんとは異なり、
**連勝数に応じて勝敗の確率が変化するシステム**を実装しています。

ブラウザ版を公開しているため、インストール不要でプレイできます。

## 工夫した点

### 連勝数に応じて変化する勝敗確率

完全なランダムで勝敗を決定するのではなく、
プレイヤーの連勝数に応じて勝率が段階的に変化するシステムを実装しました。

序盤は比較的連勝しやすく、
連勝数が増えるほど徐々に勝ちにくくなります。

単純なじゃんけんにスコアアタック要素を加えることで、
「どこまで連勝できるか」を楽しめるゲームにしています。

---

### テーブルを利用したじゃんけん判定

グー・チョキ・パーを数値として管理し、
勝ち・負け・あいこの組み合わせをLuaのテーブルとして定義しています。

```lua
RSP = {r = 1, s = 2, p = 3}

RSP_result = {
    {RSP.r, RSP.s, RSP.p}, -- あいこ
    {RSP.s, RSP.p, RSP.r}, -- 勝ち
    {RSP.p, RSP.r, RSP.s}  -- 負け
}
```

プレイヤーが選択した手をインデックスとして利用することで、
条件分岐を大量に記述せずにCPUの手を決定できるようにしています。

---

### シンプルな構成でゲーム全体を実装

ゲームの規模に合わせて構成をシンプルにし、
**じゃんけん判定、確率制御、連勝記録、入力処理、GUI表示などのゲームシステムを1つのGUIスクリプト内で実装**しています。

小規模なゲームであることを活かし、
処理の流れを1つのスクリプトから把握できる構成にしました。

---

### 連勝記録の表示

現在の連勝数と最高連勝記録を画面上に表示しています。

勝利すると連勝数が増加し、
敗北すると現在の連勝記録がリセットされます。

これにより、シンプルなじゃんけんでも繰り返し挑戦できるようにしています。
